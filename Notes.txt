---------------

Conditional Clause 
--------------------
if statement 
---------------
syntax:
--------
if condition:
    block of code
condition --> expression that returns Bool.

True --> execute the block. False --> skip the block of code

elif statement 
-----------------
syntax:
---------
elif cond:
    block of code

True --> execute the block. False --> skip the block of code

else Statement 
---------------
syntax 
---------
else:
    block of code

False --> execute the block. True --> skip the block.

Nested If 
------------

    if cond2:  
        block of code

Loop
-----------
>> It executes a block of code for multiple times.

While --> Condition based loop
For --> Sequence based loop 

While (When you don't know the no of iteration)
-------
Syntax:
----------
while cond:
    block of code

>> keep repeating the block of code for multiple times as long as the condition is True.

For Loop (number of iteration is known(preferable))
--------
Syntax:
----------
for varName in Sequence:
    block of code

Range --> to create a sequence with sequential Numbers 
-----------------------------------------------------------
range(len) --> range(5) --> [0,1,2,3,4]
range(start,end) --> range(14,20) --> [14,15,16,17,18,19]
range(start,end,step) --> range(2,20,1)

Control Statememnts 
---------------------
